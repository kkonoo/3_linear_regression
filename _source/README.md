# _source — 작업용 원자료 (사이트에 렌더링되지 않음)

`S_S_2_Linear_regression (GT)` 에서 뽑아온 참고 자료입니다.
Quarto는 `_` 로 시작하는 폴더를 무시하므로 사이트에는 포함되지 않습니다.

| 폴더 | 내용 |
|---|---|
| `notes/` | 원본 docx 19개를 pandoc으로 변환한 markdown (수식·그림은 `media/` 참조로 남아 있음) |
| `code/`  | 원자료에 포함된 R 스크립트 13개 |
| `media/` | 원본 docx에서 추출한 이미지 545개 — **git 제외** (`.gitignore`) |

## 이미지 처리 방침

- **수식 이미지 (약 263개)** → LaTeX로 다시 타이핑 (`$...$`, `$$...$$`)
- **플롯 이미지 (약 235개)** → R 코드 청크로 재생성 (`_quarto.yml`의 `fig-format: svg`)
- **개념 다이어그램** → `images/` 아래 손으로 작성한 SVG

챕터별 이미지 개수는 각 qmd 상단 "원자료" callout에 적어두었습니다.
