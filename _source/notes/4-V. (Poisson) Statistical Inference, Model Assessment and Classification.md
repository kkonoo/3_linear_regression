5)  **Overdispersion parameter** $\phi$

```{=html}
<!-- -->
```
1.  Overdispersion: model로 계산되는 것보다 Y의 variability가 큰 경우

2.  Overdispersion estimate\
    $\widehat{\phi} = \frac{D}{n - p - 1}$ where D is the sum of the squared deviances (SSE의 평균)\
    If $\widehat{\phi} > 2$ = over-dispersed model

3.  Over-dispersed model ... 원래 dispersion에 parameter $\phi$ 를 더 곱해서 사용
