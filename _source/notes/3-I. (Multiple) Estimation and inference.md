2)  Multiple Interpretation

```{=html}
<!-- -->
```
1.  Estimated regression coefficient

```{=html}
<!-- -->
```
i.  **Marginal**: 한 X로만 simple regression할 때, beta

ii. **Conditional**: 여러 X (covariates) 넣고 regression했을 때, 한 x에 대한 beta

> *[보통 marginal regression coefficient랑 conditional은 다를 수 있음 (크기나 방향 자체가)]{.underline}*

2.  Causality vs association

```{=html}
<!-- -->
```
i.  **Causality**: 실험 디자인 자체를 causal을 찾을 수 있도록 짜야함 (시간 순으로 등)

ii. **Association**: observed data에서 단순하게 확인 가능

> 특히 Y = -X1 + X2 + e 이런 식이 있다고 할 때,\
> X1이랑 X2가 서로 --관계 (X)\
> X1 고정하고, [Y]{.underline}와 X2 이렇게 보는 거임 (O)

3.  Predicting variables

```{=html}
<!-- -->
```
i.  **Controlling**: Y에 대한 bias를 보정할 수 있음 ... covariates

ii. **Explanatory**: Y(우리가 보고 싶은 현상)에 대해 얼마나 설명할 수 있을 지 ... our interest

iii. **Predictive**: explanatory power는 그렇다 치고 X 가지고 Y 예측할 수 있음 ... our interest
