    4.  Normal ... 오차항의 분포는 정규분포; ![](media/image9.png){width="0.6924026684164479in" height="0.16666666666666666in"}

4)  Model parameters\
    > ... true value이기 때문에 영원히 알 수 없음. 오로지 예측만 가능 by 데이터+가정\
    > ![](media/image3.png){width="1.6805555555555556in" height="0.34799431321084867in"}

    1.  Slope: b1

    2.  Intercept: b2

    3.  Variance of deviances: sigma^2^

5)  Approach ... SE가 가장 작아지는 parameter를 찾음

    1.  SE (squared error) = (observed -- estimated)^2^\
        ![](media/image10.png){width="1.1101727909011374in" height="0.5276071741032371in"}... *Sum of SE (SSE)*\
        c.f. chi-square (X^2^) = SE/expected(estimate) ... 뭔가 (normal을 따르는 X의) 제곱의 합(∑X^2^) & df=데이터 개수\
        ![](media/image11.png){width="1.2868055555555555in" height="0.33125in"}... error = estimated residual + 선형회귀 가정\
        (normality & zero-mean & error variance = data variance)

    2.  Parameter estimator x mean, y mean일 때 SE = 0\
        ![](media/image12.png){width="1.472392825896763in" height="0.7589654418197725in"}... b = y/x니까 그런 직관적인 느낌으로

    3.  SSE = 이차식 최솟값은 미분했을 때 0 (by 선형대수)

-   **Parameter estimate으로 fitted values 표현 residuals\
    **![](media/image13.png){width="1.8406594488188976in" height="0.6391174540682415in"} **... *residual = error estimator***

-   **Mean squared error (MSE) = σ^2^(true variance; 모분산)의 estimator**\
    ![](media/image14.png){width="1.5824179790026247in" height="0.5359798775153106in"}**= σ^2^**\
    *... n-2인 이유는 이미 r 계산할 때 parameter b1, b2도 계산하고 들어가야 해서!\
    ... 근데 sample variance 비스무리하게 생기긴 했음 n-2만 빼면\
    *\* sampling distribution of sigma^2^ ... 사실 sigma도 parameter기 때문에 모르는 상황. 분포는 error가 normal이라고 가정하기 때문에 X^2^분포로 가면 됨!\
    SSE/SST하면 유의성도 계산 가능!

-   **Sample variance ... SST는 df = n-1인 X^2^ 분포\
    (Z \~ normal일 때, deviance 구할 때 true mean/mu 대신 Z bar로 대체하니까 df = n-1)**\
    ![](media/image15.png){width="1.912630139982502in" height="0.3987729658792651in"}... SST\
    ![선형회귀의 적합성 평가와 과적합을 판단하는 방법](media/image16.png){width="3.097338145231846in" height="1.6131944444444444in"}... SSR(unexplained)은 df=1\
    *(책마다 SSE, SSR을 반대로 정의하는 것도 있음!)*

-   Model parameter interpretation

1.  A positive value of $\text{β}_{\text{1}}$ : a direct relationship between x and y

2.  A negative value of $\text{β}_{\text{1}}$ : an inverse relationship between x and y

3.  A close to zero value of $\text{β}_{\text{1}}$ : not a significant association between x and y
