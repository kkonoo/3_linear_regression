4)  Notation

-   S $\subset \left\{ 1,..p \right\}$ : a subset of indices (X인 거 같은데)

-   $x_{j}$ for $j \in S$ : 한 X에 대해서 한 사람의 값

-   $\widehat{\beta}\left( S \right)$ : estimated regression coefficients for the submodel with the $\mathbf{X}_{S} =$($x_{j}$ for $j \in S$) predicting variables

-   $\widehat{Y}\left( S \right)\ :\ $fitted values for the submodel with the $\mathbf{X}_{S} =$($x_{j}$ for $j \in S$) predicting variables

-   e.g. regression assuming normality : $\widehat{Y}\left( S \right)$= $\mathbf{X}_{S}\widehat{\beta}\left( S \right)$

-   this model = the S submodel

3)  Variable Selection Criteria (CP를 정하는 것임)

```{=html}
<!-- -->
```
1.  *[Mallow's Cp]{.underline}:* $\text{Complexity~Penalty}$ *=* $\frac{2|S|{\widehat{\sigma}}^{2}}{n}$

> *(s : p 개수= model size,* ${\widehat{\sigma}}^{2}$ *: full model의 estimated variance.. 그냥 obs의 분산)*

2.  *[Akaike Information Criterion]{.underline} (AIC):* $\text{Complexity~Penalty}$ *=* $\frac{2|S|{\widehat{\sigma}}^{2}}{n}$

> (${\widehat{\sigma}}^{2}$ *: true variance..이지만 모르기 때문에 역시나 estimate으로.. 그럼 위랑 똑같?)*

3.  *[Bayesian Information Criterion]{.underline} (BIC):* $\text{Complexity~Penalty} =$ $\frac{|S|\sigma^{2}\log(n)}{n}$

> (${\widehat{\sigma}}^{2}$ *: true variance.. 역시나 모르게 때문에. 그리고 log를 곱해서 CP를 더 크게 하는거라 prediction model selection에서 많이 씀)*

4.  *[Leave-one-out Cross Validation]{.underline}:*

    -   ${\widehat{R}}_{\text{CV}}\left( S \right) = \ \frac{1}{n}\sum_{i = 1}^{n}\left( {\widehat{Y}}_{\left( i \right)}\left( S \right) - Y_{i} \right)^{2}$

> *(*${\widehat{Y}}_{\left( i \right)}\left( S \right)$ *: 샘플 (i) 빼고 만든 모델에서 y hat)*

-   ${\widehat{R}}_{\text{CV}}\left( S \right)\  \approx R_{\text{tr}}\left( S \right) +$ $\frac{2|S|{\widehat{\sigma}}^{2}(S)}{n}$

> *(*${\widehat{\sigma}}^{2}\left( S \right)$ *: S submodel에서 estimated variance)*

4)  Generalized Linear Models

-   Logistic regression & Poisson regression.. MSE같은 거라고 했으니까 deviance residual이랑 똑같이 생긴..

-   $R_{\text{tr}}\left( S \right) = \ \frac{1}{n}\sum_{i = 1}^{n}{\text{2}\text{Y}_{\text{i}}\text{log}\lbrack\text{Y}_{\text{i}}\text{/}{\widehat{\text{Y}}}_{\text{i}}\text{(S)]+2(}\text{n}_{\text{i}}\text{-}\text{Y}_{\text{i}})\text{log}\lbrack{(\text{n}}_{\text{i}}\text{-}\text{Y}_{\text{i}})\text{/}{(\text{n}}_{\text{i}}\text{-}{\widehat{\text{Y}}}_{\text{i}}(S))\text{])}}$

> (S: submodel, ${\widehat{Y}}_{i}\left( S \right)\ $*:* the fitted response for model S, $Y_{i}$ the future observation)

-   **Correct for the bias :** $R_{\text{tr}}\left( S \right) + Complexity\ Penalty$

-   AIC & BIC가 GLM에서는 많이 쓰임!
